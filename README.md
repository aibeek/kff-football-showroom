# Qazaqstan Football Showroom

Интерактивная 3D-раздевалка казахстанского футбола. Форма сборной и клубов, официальный мяч adidas Conext 26, корзина и стартовое превью.

## Локальный запуск в Windows

Из корня репозитория выполните команду в cmd.

```cmd
py -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Запуск через file:// не поддерживается из-за модульных скриптов и загрузки ресурсов.

## Устройство проекта

- dist/index.html и style.css — интерфейс и адаптивная компоновка.
- boot.js — предварительная загрузка и стартовое превью.
- app.js — каталог, корзина, управление и анимация появления мяча.
- model.js, rack-webgl.js, cloth-material.js — Three.js, 3D-модели и ткань.
- software-3d.js — программный рендер при недоступности WebGL.
- assets — локальные модели, текстуры, фотографии и эмблемы.
